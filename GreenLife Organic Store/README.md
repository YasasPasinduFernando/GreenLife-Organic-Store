# GreenLife Organic Store

This is a Windows Forms .NET 8 application for a small e-commerce store. It includes product, category, user, cart and order management, and an image store for product images.

How to run
1. Open the solution in Visual Studio 2022 or later.
2. Build the solution.
3. Run the project `GreenLife Organic Store`.

Notes
- The application stores images in an `Images` folder under the application base directory.
- Remove or update any connection strings or secrets in `appsettings.json` or similar before sharing publicly.
